# 배선/납땜 가이드 (XIAO ESP32S3 노드 6종)

이 문서는 `firmware/`의 6개 노드(`env_presence_node`, `relay_node`, `power_monitor_node`, `power_relay_node`, `presence_vision_node`, `life_pattern_vision_node`)를 실제로 조립할 때 보는 하드웨어 조립 가이드다. 코드/설정 방법은 `firmware/README.md`, 배포는 `backend/DEPLOY_AWS.md` 참고.

## 0. 안전 수칙 (필독)

- **`power_monitor_node`/`power_relay_node`(PZEM-004T)와 `relay_node`/`power_relay_node`(릴레이)는 220V/110V AC 전원선에 직접 연결된다.** 감전·화재 위험이 있으니 아래를 반드시 지킨다.
  1. **배선 작업은 항상 전원 코드를 콘센트에서 뽑은 상태에서 한다.** 배선이 끝나고 절연 확인까지 마친 뒤에만 통전한다.
  2. AC가 물리는 부분(PZEM 단자대, 릴레이 COM/NO/NC 단자, 전선 피복 벗긴 부분)은 **절연 테이프나 절연 인클로저(플라스틱 케이스) 안에 완전히 가둔다.** 맨 구리선이 겉으로 드러난 채로 두지 않는다.
  3. line(활선)/load(부하) 방향을 부품 실크스크린이나 데이터시트로 반드시 확인 후 연결한다. 방향이 바뀌면 릴레이가 꺼져 있어도 부하 쪽에 활선이 걸려있는 상태가 될 수 있다.
  4. 통전 상태에서는 절대 배선을 만지거나 케이스를 열지 않는다.
  5. 부하는 정격 전류 내로 유지한다 (아래 각 노드 섹션 참고). 여유 없이 정격에 딱 맞춰 쓰지 않는다.
  6. 완성 후 첫 통전은 저전력 기기(예: 스탠드 조명)로 먼저 테스트하고, 문제없음을 확인한 뒤 실제 데모 기기(에어컨/선풍기 등)로 넘어간다.
- ESP32 쪽 로직(3.3V)과 AC 쪽(220V/110V)은 물리적으로 완전히 분리되어 있어야 한다. 저전압 배선과 AC 배선이 케이스 안에서 서로 닿지 않게 케이블 타이 등으로 정리한다.
- 잘 모르겠으면 무리해서 진행하지 말고 전기 관련 지식이 있는 사람에게 검수받는다.

## 1. 공통 준비물

**공구**
- 납땜인두(온도조절 가능한 것 권장, 팁 온도 320~350℃) + 인두대
- 실납(권장: 유연납 Sn60/Pb40 또는 무연납, 0.6~0.8mm) + 플럭스(선택, 납땜 잘 안 붙을 때)
- 롱노즈 펜치, 니퍼(전선 피복 제거/절단용)
- 와이어 스트리퍼(피복 벗기기, 니퍼로도 가능하지만 심선 손상 위험 있어 권장)
- 멀티미터(통전/전압 확인 필수 — 특히 AC 배선 후)
- 브레드보드 + 점퍼선(시제품 단계) 또는 만능기판(perfboard, 고정형으로 만들 때)
- 글루건 또는 케이블타이(배선 고정, AC 쪽은 특히 흔들려서 단자가 헐거워지지 않게)
- 절연테이프, 수축튜브(AC 연결부 절연 마감용)

**부자재**
- 각 노드별 센서/모듈 (아래 3장 참고)
- 핀 헤더(2.54mm 피치, XIAO 보드 자체에 헤더가 안 붙어 있으면 직접 납땜해야 함)
- AC 전원 코드/멀티탭 (릴레이·PZEM 노드용, 중간에 끊어서 배선에 넣을 것)

## 2. XIAO ESP32S3 보드 자체 납땜 (핀 헤더)

Seeed Studio XIAO ESP32S3는 보통 핀 헤더가 **딸려오지만 미리 납땜되어 있지 않다.** 브레드보드에 꽂아 쓰려면 직접 붙여야 한다.

1. 핀 헤더(수/암, 구성품에 따라 다름)를 보드 양쪽 가장자리 구멍에 꽂는다.
2. 브레드보드에 헤더를 먼저 꽂아서 고정한 채로 그 위에 보드를 얹으면 헤더가 수직으로 서서 납땜하기 쉽다(브레드보드가 지그 역할).
3. 각 핀 구멍마다 인두를 2~3초 대고 납을 흘려 넣는다 — 인두를 오래 대고 있으면 보드나 부품이 열손상을 입을 수 있으니 핀 하나당 3초 이내로 끝낸다.
4. 전부 납땜한 뒤 멀티미터 연속성(continuity) 모드로 인접한 두 핀이 실수로 붙어있지 않은지(브릿지) 확인한다.
5. **XIAO ESP32S3 Sense**(카메라 버전)를 쓰는 경우, 카메라 확장보드가 이미 별도 조립되어 오거나(구성품에 따라 다름) 메인 보드 하단 패드에 납땜/커넥터로 결합해야 한다 — Seeed 공식 조립 가이드(패키지 동봉 설명서)를 따른다. 카메라 FPC 리본 케이블은 파란 면이 위/아래 어느 쪽인지 커넥터 락 방향에 맞춰 삽입하고, 반드시 커넥터의 검은 잠금 탭을 눌러 고정한다 — 헐겁게 꽂으면 부팅은 되지만 카메라 초기화가 계속 실패한다.

## 3. 노드별 배선

공통: 모든 센서 모듈의 VCC는 XIAO의 **3V3 핀**(5V 아님, 아래 개별 주의사항 예외 있음)에, GND는 XIAO의 GND 핀에 연결한다.

### 3-1. `env_presence_node` — BME280(온습도) + PIR(HC-SR501, 재실 감지)

| 모듈 핀 | XIAO ESP32S3 핀 | 비고 |
|---|---|---|
| BME280 VCC | 3V3 | |
| BME280 GND | GND | |
| BME280 SDA | D4 | `Wire.begin()` 기본값 |
| BME280 SCL | D5 | `Wire.begin()` 기본값 |
| PIR VCC | **3V3 (반드시)** | 5V로 주면 PIR의 OUT 신호 레벨이 ESP32 GPIO 안전 전압(3.3V)을 넘어 GPIO가 손상될 수 있다 |
| PIR GND | GND | |
| PIR OUT | D0 | `config.h`의 `PIR_PIN`과 일치해야 함(기본 D0) |

PIR 모듈에 감도(sensitivity)/지연시간(time delay) 트리머가 있으면, 감도는 중간~약간 낮게, 지연시간은 최소로 돌려서 시작한다(지연시간이 길면 움직임이 멈춘 뒤에도 한참 HIGH를 유지해서 "무움직임 감지"가 늦어짐 — 취침 감지 기능이 이 값을 그대로 쓰므로 중요).

### 3-2. `relay_node` — 릴레이 모듈(기기 on/off)

**저전압(제어) 쪽**

| 모듈 핀 | XIAO ESP32S3 핀 |
|---|---|
| 릴레이 VCC | 3V3 (모듈에 따라 5V 요구 시 USB 5V 핀 사용 — 배터리 구동 시엔 5V 핀이 죽어있으니 주의) |
| 릴레이 GND | GND |
| 릴레이 IN | D1 (`config.h`의 `RELAY_PIN`) |

**AC(고전압) 쪽 — 0장 안전 수칙 필독 후 작업**

전원 코드를 중간에서 자른다고 생각하면 된다: 코드의 **활선(line)만** 끊어서 릴레이의 COM과 NO(normally open) 단자 사이에 끼워 넣는다. 중성선(neutral)은 끊지 않고 그대로 통과시킨다.

```
[콘센트] --(활선)--> [릴레이 COM] [릴레이 NO] --(활선)--> [부하(에어컨/선풍기 등)]
[콘센트] ------------------(중성선, 그대로 직결)-----------------> [부하]
```

- 저가 옵토릴레이 보드는 대부분 **active-LOW**(IN에 LOW를 줘야 릴레이 동작)다. `config.h.example`의 `RELAY_ACTIVE_LEVEL LOW`가 기본값이며, 실제 보드로 멀티미터/청각(딸깍 소리)으로 극성을 확인한 뒤 다르면 `HIGH`로 바꾼다.
- 릴레이 코일측이 5V 전용 모듈이면 배터리 단독 구동 시 동작하지 않는다(XIAO의 5V 핀은 USB 급전 시에만 살아있음) — 데모 때는 USB 전원으로 구동할 것.

### 3-3. `power_monitor_node` — PZEM-004T v3(전력 측정 전용)

**저전압(통신) 쪽**

| PZEM 핀 | XIAO ESP32S3 핀 |
|---|---|
| PZEM 5V | 5V (USB 급전 시에만 사용 가능) |
| PZEM GND | GND |
| PZEM TX | D7 (XIAO의 RX) |
| PZEM RX | D6 (XIAO의 TX) |

TX-RX는 서로 **교차** 연결한다(PZEM TX → XIAO RX, PZEM RX → XIAO TX). 그대로 나란히 연결(TX-TX, RX-RX)하면 통신이 안 된다.

**AC 쪽**

PZEM-004T v3는 두 종류가 있다 — 구매한 모듈이 어느 쪽인지 확인:
- **10A(직결)형**: 단자대에 L/N IN, L/N OUT이 있고 활선/중성선 모두 직접 관통시켜 배선한다. 최대 10A(220V 기준 약 2.2kW)까지.
- **100A(CT클램프)형**: 전원선은 자르지 않고 그대로 두고, 별도 CT(분할형 클램프)를 **활선(line)에만** 끼워서 측정한다. 중성선에 끼우면 측정이 안 되거나 부정확하다.

어느 쪽이든 AC 배선 자체는 콘센트→PZEM→부하 순서로 직렬로 물린다(측정만 하고 차단은 안 하므로 릴레이처럼 스위칭 개념은 없음).

### 3-4. `power_relay_node` — PZEM + 릴레이 통합(스마트플러그형)

3-2(릴레이)와 3-3(PZEM) 배선을 그대로 합친 것이다. 저전압 쪽은 D1(릴레이 IN), D6/D7(PZEM TX/RX)을 각각 개별 연결하면 되고, **AC 쪽은 아래 순서로 직렬 연결**한다:

```
[콘센트] --(활선)--> [PZEM L-IN] [PZEM L-OUT] --(활선)--> [릴레이 COM] [릴레이 NO] --(활선)--> [부하]
[콘센트] --------------------------(중성선, PZEM 통과 후 그대로 직결)---------------------------> [부하]
```

PZEM을 먼저 지나야 릴레이가 꺼져도(부하가 차단돼도) PZEM 자체는 계속 전원을 공급받아 통신이 끊기지 않는다. 순서를 반대로 하면 릴레이 OFF 시 PZEM도 같이 죽어서 마지막 측정값이 멈춘 채로 남는다.

### 3-5. `presence_vision_node` / `life_pattern_vision_node` — 카메라(XIAO ESP32S3 Sense)

**추가 배선/납땜 없음.** 2장에서 설명한 Sense 확장보드 결합(카메라 FPC 케이블 + 보드 커넥터/헤더)만 되어 있으면 끝이다. GPIO 핀들(`XCLK`=10, `SIOD`=40 등, `.ino` 상단 참고)은 Sense 보드 내부에서 이미 고정 배선되어 있어 사용자가 직접 연결할 부분이 없다.

주의: 이 두 노드는 카메라+비전 모델이 PSRAM을 많이 쓰므로, Arduino IDE 빌드 옵션에서 **Tools → PSRAM: OPI PSRAM**로 반드시 맞춰야 한다(펌웨어 코드가 아니라 빌드 설정 문제이므로 배선과는 무관하지만 자주 놓치는 부분이라 여기 같이 적어둔다).

## 4. 전원 공급

- **USB-C**: 가장 간단하고 안정적. 데모 당일은 이 방식을 기본으로 한다(릴레이 5V 코일도 이걸로 커버됨).
- **LiPo 배터리**: XIAO ESP32S3 보드 옆면에 JST 커넥터가 있어 단선 배터리를 바로 꽂을 수 있다. 단, 5V 핀이 죽으므로 5V를 요구하는 릴레이 모듈과는 궁합이 안 맞을 수 있다(3.3V 구동 릴레이 모듈이면 문제없음). 배터리 극성을 반드시 확인 — 반대로 꽂으면 보드가 손상된다.

## 5. 통전 전 최종 점검 체크리스트

- [ ] 멀티미터 연속성 모드로 GND끼리, VCC끼리 서로 다른 전위가 실수로 안 붙어있는지 확인
- [ ] AC 활선/중성선이 릴레이 COM/NO, PZEM L-IN/L-OUT에 정확한 방향으로 들어갔는지 재확인
- [ ] AC가 물리는 모든 접점이 절연테이프/인클로저로 완전히 덮였는지 육안 확인
- [ ] 저전압 배선과 AC 배선이 케이스 안에서 서로 닿지 않는지 확인
- [ ] `config.h`의 `DEVICE_ID`/`ROOM`/`RELAY_ACTIVE_LEVEL`이 이 보드에 맞게 채워져 있는지 확인
- [ ] 위 항목 전부 통과 후에만 콘센트에 꽂는다 — 처음 통전 시 저전력 기기로 먼저 테스트

## 6. 자주 하는 실수

- **PIR을 5V에 물림** → GPIO 손상 가능. 반드시 3V3.
- **PZEM TX/RX를 교차 없이 나란히 연결** → 통신 안 됨(readings가 전부 0/NAN으로 옴).
- **릴레이 극성(active-high/low) 확인 없이 코드만 믿음** → 릴레이가 항상 반대로 동작(꺼야 할 때 켜짐)하는데, 이 상태로 통전 테스트하면 위험. 반드시 저전압 상태에서 딸깍 소리/LED로 먼저 검증 후 AC 연결.
- **power_relay_node에서 릴레이를 PZEM보다 먼저 배치** → 릴레이 OFF 시 PZEM 응답 끊김.
- **AC 배선 후 절연 마감을 생략하고 바로 통전** → 감전/합선 위험. 반드시 케이스에 넣거나 절연테이프로 완전히 감싼 뒤 통전.
- **인두를 한 핀에 5초 이상 대고 있음** → 보드/부품 열손상. 안 붙으면 일단 떼고 팁을 닦은 뒤 다시 시도.
